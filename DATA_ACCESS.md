# Data access

The repository distributes code and a header-only classification template. Synthetic records are generated by the tests; they are not observations from the research.

| Project | Inputs required for the research workflow |
|---|---|
| Data centers and electricity | ERCOT settlement prices, generation and load workbooks, and a locally prepared facility tracker. The research tracker draws on Bloomberg/DC Byte material and is not included. |
| Climate and credit | An authorized DealScan extract, project-specific EXIOBASE-to-SIC tables, and a SIC-to-NACE crosswalk. None is included. |
| Electricity finance | An authorized DealScan extract and a documented borrower-classification override file. The repository includes only the override column names. |
| Carbon pass-through | Locally cleaned ISO New England offer records, fuel prices, secondary-market allowance prices, and prior exposure classifications. These intermediate datasets are not included. |

Access to a source does not automatically grant redistribution rights. Obtain the appropriate access and prepare the listed schemas before running a workflow. The project READMEs identify the expected files; this release does not provide downloaders or a complete raw-to-results pipeline for every source.

Raw and intermediate data, generated results, logs, local review records, and environment files are ignored by Git. Scripts write only within the project copy unless an explicit output argument is supplied.

No open-source license has been assigned in this release. Publication on GitHub should not be read as a grant of rights to third-party data or coauthored materials.
